# Project Memory & Context

## Context
- The project is an "AI Resume Analyzer" utilizing `React` and `Flask`.
- Valid original database credentials have been populated into the backend environment variables by the user locally.

## File Mapping
- Models: `User`, `Resume`, `JobDescription`, `Analysis` are located in `backend/app/models/`.
- App factory located in `backend/app/__init__.py`.
- Entry point mapped to `backend/main.py`.
